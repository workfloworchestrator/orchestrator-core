# 5.5 Upgrade Guide

In this document we describe changes to be aware of when upgrading from `orchestrator-core` v5.4 to v5.5.

## About 5.5

This release introduces:
- [Deprecations](#deprecations): code/functionality that still works but will be removed in v6

## Deprecations

The following are deprecated and will be removed in a future major version. They may raise a `DeprecationWarning` when
used which you can choose to suppress.

- `orchestrator.core.services.processes`: `StateMerger` is deprecated in favor of the pure `merge_state()` function.
  You can inspect [#1918](https://github.com/workfloworchestrator/orchestrator-core/pull/1918) how to use the new
  function, or to copy the old definition. (removal tracked in [#1963](https://github.com/workfloworchestrator/orchestrator-core/issues/1963))
