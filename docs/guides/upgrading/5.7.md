## Configurable connection pool

`DATABASE_POOL_SIZE`, `DATABASE_MAX_OVERFLOW` and `DATABASE_POOL_TIMEOUT` set `pool_size`, `max_overflow` and
`pool_timeout` of `create_engine()`. For backwards compatibility, a pool key patched into `ENGINE_ARGUMENTS` to a value
other than its built-in default overrides its setting. A patch equal to the default does nothing. See [Connection pool](../../reference-docs/database.md#connection-pool).

## Pool exhaustion returns 503

A request that waits longer than `DATABASE_POOL_TIMEOUT` for a connection now gets `503 Service Unavailable` with a
`Retry-After: 5` header, instead of a `500` from the unhandled SQLAlchemy timeout. GraphQL still answers `200` with
the error in its `errors` list. Treat `503` as retryable.

## Bulk process actions

`POST /api/processes/bulk` applies `resume`, `abort`, `delete` or `note` to a list of processes in one request. The
request is rejected as a whole when a process is unknown (`404`) or the action cannot be applied to it (`409`).
