# Parallelization
<!-- diataxis: -->

For some workloads performed by the orchestrator, it can be beneficial to run workflows or workflow steps in parallel.

## Styles of Parallelization
<!-- diataxis: -->

There are two different ways of running in parallel: "foreach"-style and "true" parallel. Their use in different
organizations is described in this section of the documentation.
